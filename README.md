# Terranxt site (static)

Open index.html or use VS Code Live Server. No build step.

- css/styles.css: theme (colours and fonts in :root)
- js/layout.js: header and footer, edit once
- js/forms.js: forms and demo booking. Set Odoo endpoints in TX_CONFIG
- assets/: images, logos, videos

Placeholders (dashed boxes) show what to place and the size. Replace with <img> or <video>.
Store links are # until the apps are listed. Legal pages need real text.
